## MP4 サムネイル / 先頭フレーム（frame 0）の実態

**結論: 静止画背景で画像を指定しているときの「動画を生成」では、MP4 カバー art は未加工静止画（リサイズのみ）。動画背景のみ・画像なしのときは従来どおりエンコード済み先頭フレーム。**

### 1. 標準経路（MediaRecorder → FFmpeg）

1. `captureStream` でキャンバスを WebM 録画（スペクトラム・エフェクト・背景合成済み）
2. `generateMp4Video`（`lib/Ffmpeg.ts`）で remux / loudnorm
3. **サムネ JPEG**
   - **静止画背景**（`backgroundMediaMode === "stills"`）かつギャラリー画像あり → `buildMp4StillThumbnailJpeg`（`lib/mp4Thumbnail.ts`）で **原画 JPEG** を `thumbnailJpeg` として渡す
   - 上記以外（動画背景・画像未選択・JPEG 化失敗）→ `extractVideoFrameThumbnailJpeg` で **完成 MP4 の先頭動画フレーム**（長辺 ≤ 1920）

動画本体の先頭フレームは引き続き **録画された合成映像** 。カバー art だけが静止画原画になる。

### 2. QuickVideoEncoder（UI 非表示・コード残存）

- `lib/QuickVideoEncoder.ts`: オフスクリーン Canvas + `MediaRecorder`
- 背景は `drawImage`、スペクトラムは簡易 `drawSpectrum`（本番 `drawBars` より機能が少ない）
- MP4 化は同じ `generateMp4Video` → 静止画背景時は **原画 JPEG**、それ以外は先頭フレーム

### 3. 静止画 JPEG 経路（標準 UI で使用）

- `lib/mp4Thumbnail.ts` — `imageElementToThumbnailJpeg` で静止画を JPEG 化
- `pages/index.tsx` — `buildMp4StillThumbnailJpeg` が `onRecordMovie` / QuickEncode から `thumbnailJpeg` を渡す
- FFmpeg は **caller JPEG** を優先（`ffmpeg: thumbnail from caller JPEG`）
- **スペクトラムなし**（リサイズ・出力解像度への収めのみ）。動画本体フレームとは別物

### 4. MediaRecorder 単体

- WebM 内のフレーム 0 もキャプチャストリーム由来で、**プレビュー/録画と同じ合成結果**

| 経路 | カバー art (`attached_pic`) | 動画の frame 0 |
|------|------------------------------|----------------|
| MediaRecorder → FFmpeg（静止画背景あり） | **原画 JPEG**（リサイズのみ） | **合成済み** |
| MediaRecorder → FFmpeg（動画背景／画像なし） | **合成の先頭フレーム** | **合成済み** |
| QuickVideoEncoder → FFmpeg（静止画あり） | **原画 JPEG** | **簡易合成** |
| QuickVideoEncoder（静止画なし） | **簡易合成の先頭フレーム** | **簡易合成** |

関連: [FFMPEG.md](./FFMPEG.md)、`lib/Ffmpeg.ts`、`lib/mp4Thumbnail.ts`。

## 追記（2026-06-13）— 描画・字幕パフォーマンス（PR [#41](https://github.com/kuwa2005/music-waves-visualizer/pull/41)）

ブランチ `work/layout-overhaul-20260526` の v1.0.6 以降コミット群。主な参照: `a782378`（WebGL 背景・FFT スクラッチ）、`54be710`（水滴 LineBatch）、`c77b097`〜`91d51ea`（字幕 round 1–4）。

### 描画ループ（Canvas 2D / WebGL 共通方針）

| 項目 | 実装 |
|------|------|
| FFT スクラッチ | `lib/Canvas.ts` — `canvasFftBufferScratch` 等。`lib/WebGLRenderer.ts` — `fftBufferScratch` 等。毎フレーム `new Uint8Array` を廃止 |
| WebGL 背景 | `ensureBgTempCanvas` + `uploadBgTempCanvasToTexture`。サイズ不変時は `texSubImage2D` |
| 水滴 WebGL | `LineBatch`（`addLineToBatch` / `flushLineBatch`）でリップル線を 1 draw call に集約 |
| 動画背景プレビュー | 30 fps 間引き（録画は最大 60 fps 維持） |
| モード 6 | エフェクト不要時の二重 `getByteFrequencyData` を解消 |

### 字幕アーキテクチャ（`lib/subtitles.ts`）

| 層 | 内容 |
|----|------|
| **キャッシュ** | `subtitleLayerCache` / `titleLayerCache` — キーは解像度 + キュー stem + スタイル |
| **プリフェッチ** | 再生中の次キューを `requestIdleCallback`（fallback: `setTimeout(0)`）で先行 `buildTextOverlayLayer` |
| **キュー検索** | `getActiveCue` — ヒント + 二分探索（`lastCueSearchHint`） |
| **SRT 解析** | `parseSrtAsync` — 大きいファイルは行走査 + 定期 `yieldToMain`；小さいものは同期 `parseSrt` |
| **競合防止** | `loadSubtitleSeqRef`（`pages/index.tsx`）— 連続ロード・作者パネル適用時に古い async 結果を破棄 |
| **WebGL 合成** | 字幕・タイトルは Canvas2D レイヤー → WebGL テクスチャ。デュアルスロット + idle で次フレーム用 UP を先行（`schedulePrefetchTextOverlayTextureUpload`） |
| **UI** | 字幕タブ表示 ON/OFF、SRT 読込時の不要なアニメ再起動を防止 |

開発者モードの計測 HUD: [DEVELOPER_MODE.md](./DEVELOPER_MODE.md)。
