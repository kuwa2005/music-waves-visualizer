# 今日は、自分の一日を少しだけ大切にする日

朝、カレンダーの日付を目にしたとき、ふと「今日は何の日だろう」と思うことがあります。

世の中には、名前のついた記念日がたくさんあります。歴史に残る日、誰かの誕生日、何かが始まった日。けれど本当は、カレンダーに印がなくても、どんな一日にも「意味を見つける余白」は残っています。

たとえば、いつもより少し早く起きられた日。

気になっていた本を、ようやく一ページだけ開けた日。

しばらく連絡できていなかった友人に、短いメッセージを送れた日。

それは大きな出来事ではないかもしれません。誰かに話せば「それだけ？」と言われるようなことかもしれません。それでも、自分の中では小さく空気が変わる瞬間があります。後から振り返ってみると、暮らしの向きがほんの少し変わったのは、案外そんな何気ない一日だったりします。

記念日は、過去を思い出すためだけのものではありません。

「今日を少し丁寧に扱ってみよう」と思い出させてくれる、ささやかな合図でもあります。

名前のある日も、まだ名前のない日も、一度きりです。特別な予定がなくても、ドラマチックな変化が起きなくても、今日という日はちゃんと今日だけのものです。

だから今日は、何かを大きく変えようとしなくても大丈夫。

机の上を少し片づける。

温かい飲み物を、急がずに味わう。

気になっていたことを、ひとつだけ前に進める。

そんな小さな行動で十分です。大げさな決意よりも、続けられそうなひと手間のほうが、明日の自分をそっと助けてくれることがあります。

今日を特別にするのは、出来事の大きさではなく、こちらのまなざしなのかもしれません。

「何でもない日」と通り過ぎることもできます。

でも、「自分の一日を少しだけ大切にする日」と決めてしまえば、同じ木曜日の見え方が少し変わります。

今日は何の日。

そう聞かれたら、こう答えてみます。

今日は、自分の一日を少しだけ大切にする日。

小さく整えて、小さく始めて、小さく満たされる。

そんな一日にしていきましょう。
