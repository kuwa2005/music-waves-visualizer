# Music Waves Visualizer（改） プライバシーポリシー

Music Waves Visualizer（改）（以下「本サービス」）は、画像・音声から動画を生成する Web サービスです。  
本ポリシーは、本サービスにおけるユーザー情報等の取扱いについて定めます。

---

## 1. 取得する情報

本サービスは、提供形態や設定に応じて、以下の情報を取得する場合があります。

### 1.1 アクセス情報（サーバーログ）

本サービスをホスティングする Web サーバー／CDN の一般的なログとして、以下が記録される場合があります。

- IPアドレス
- ユーザーエージェント（ブラウザ種類・OS等）
- アクセス日時
- リファラ（参照元ページ）
- リクエストURL、レスポンスコード など

### 1.2 端末内に保存される情報（Cookie・ブラウザストレージ）

本サービスは利便性向上のため、ブラウザの **第一党 Cookie**（`SameSite=Lax`、用途は主に UI 設定の復元）に、表示調整・エフェクト・音量・解像度プリセット等の設定値を保存します。  
**読み込んだ画像・音楽ファイルの内容、タイトル用の自由記述テキスト、SRT 字幕の本文は保存しません**（字幕・タイトルの見た目設定の ON/OFF やスタイルは保存対象に含まれる場合があります）。

過去のバージョンで保存された **LocalStorage** の設定は、初回読み取り時に Cookie 側へ移行され、重複キーは削除される場合があります。  
いずれもユーザーの端末内に留まり、運営者がサーバー側で直接取得するものではありません。

---

## 2. アップロードデータ（画像・音声・生成動画）の取扱い（保存有無）

本サービスは、通常、ユーザーが選択した画像・音声ファイルを **ユーザーのブラウザ（端末）内で処理** し、動画（mp4）を生成します。

- **運営者のサーバーへ画像・音声ファイルそのものをアップロードして保存する機能はありません。**
- 生成された mp4 も、通常はブラウザ上で生成され、ユーザーの操作により端末へダウンロードされます。

ただし、以下の外部リソースが読み込まれる場合があります（ユーザーコンテンツそのものを送信する目的ではありません）。

- ffmpeg.wasm の実行ファイル等（例: `unpkg.com` からの読み込み）

- 利用状況の分析（サーバーログ等に基づく場合）
