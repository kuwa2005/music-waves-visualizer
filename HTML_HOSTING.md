# Hosting Static HTML (`visualizer/`)

The `visualizer/` directory generated by `npm run build:html` is a **complete static HTML build** (Next.js `next export` output). It is configured for the `/visualizer` path by default.

---

## 1. Default Usage (deploy to `/visualizer`)

1. Build at project root:

   ```bash
   npm install --legacy-peer-deps
   npm run build:html
   ```

   > **Note:** `postinstall` copies `@ffmpeg/core` into `public/ffmpeg-core/` for same-origin WASM loading. See [docs/BUILD.md](./docs/BUILD.md) and [docs/FFMPEG.md](./docs/FFMPEG.md).

2. Upload the contents of `visualizer/` to the server's `visualizer` directory.

   - Example: Place `index.html`, `_next/`, `.htaccess`, `README.txt` in `public_html/visualizer/`

3. Access:

   ```
   https://your-domain/visualizer/
   ```

> **Common 404 errors**  
> If `_buildManifest.js` / `_ssgManifest.js` / `index-*.js` return 404, you likely:
> - Placed files outside `visualizer/`
> - Forgot to upload `_next/` files

---

## 2. Custom Path (e.g. `/mwv`)

Edit `next.config.js` before building:

```js
basePath: '/mwv',
assetPrefix: '/mwv',
```

Then run `npm run build:html` and upload to the server's `/mwv` directory.

---

## 3. `.htaccess` and MP4 Generation

The `.htaccess` in `visualizer/` sets headers for SharedArrayBuffer (FFmpeg WASM). Without these headers, waveform display works but MP4 download may not. For non-Apache servers, configure equivalent headers.
